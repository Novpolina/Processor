# Stack-based Processor

Учебная виртуальная машина на C++: ассемблер переводит текстовую программу в машинное представление, после чего стековый процессор выполняет команды.

## Возможности

- арифметические операции и работа со стеком;
- условные и безусловные переходы;
- ввод-вывод и остановка программы;
- дампы ассемблера и состояния выполнения.

## Запуск

```bash
make
./t
```

Исходная программа задаётся в `code.txt`; промежуточный код сохраняется в `asm.txt`.
